# Integration contract v1
TypeScript source imports use explicit .ts extensions. Node 24 runs server/tests with strip-types. No enums or parameter properties. Modules own disjoint files.
Core module src/core/tournament.ts exports types and functions; core auction module src/core/auction.ts exports types and functions. Server owns src/server/*.ts. Web owns src/web/app.ts and style.css + index.html. Game owns src/core/cricket.ts and src/web/game.ts.
Web uses REST /api (default same origin, configurable API base in localStorage acpl-api). Auth Bearer opaque token. POST /api/guest {name} => {token,user:{id,name}}. GET /api/tournaments => array. POST /api/tournaments {name,teamCount,overs,purse} => tournament. GET /api/tournaments/:id => full tournament aggregate {id,name,hostId,status,teams,players,auction,fixtures,standings,playoffs}. POST /api/tournaments/:id/join {name} => team. POST /api/tournaments/:id/action {type,...} types startAuction,nominate(playerId),bid(amount,requestId),closeLot,finishAuction,selectXI(playerIds,captainId,keeperId),fixtures(format),startMatch(fixtureId),advancePlayoffs. Return full aggregate or match {id,...}. Host-only privileged actions; bid from own team. Use websocket /ws?token=... then {type:'subscribe',tournamentId} and server {type:'tournament',data:aggregate}; {type:'joinMatch',matchId} then {type:'match',data:matchState}; {type:'input',matchId,sequence,action:{type,...}}.
3D Game API export mountGame(container:HTMLElement, options:{mode:'practice'|'online',matchId?:string,userId?:string,sendInput?:(action:GameInput)=>void,onExit?:()=>void}): {dispose():void,update(state:MatchState):void}; imports from ../core/cricket.ts. Practice local engine same rules but explicitly noncompetitive.
Cricket API createMatch(id:string,teamA:MatchTeam,teamB:MatchTeam,overs:number):MatchState; stepMatch(s:MatchState,dt:number):void; applyInput(s:MatchState,userId:string,sequence:number,input:GameInput):void; MatchTeam {id,name,ownerId,players:CricketPlayer[]} CricketPlayer {id,name,batting,bowling,power,timing,accuracy,stamina,role:string}; MatchState {id,teams:[MatchTeam,MatchTeam],batting:number,innings:number,phase:string,ball:{x,y,z,vx,vy,vz},runs:number,wickets:number,legalBalls:number,overs:number,target:number|null,winnerId:string|null,events:..., ...}. Inputs bowl {type:'bowl',targetX:number,speed:number,spin:number}, shot {type:'shot',direction:number,power:number,loft:boolean}, run {type:'run'}, next {type:'next'}. Ball moves from z=-9 to batter z=8. Server 30Hz. Client renders all state. Scores determined by physics, contact, runs, wickets. Server derives result scorecard at phase complete. Tournament result commits server-only.
